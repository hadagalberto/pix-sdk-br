# Independent review — fix report (milestone 7)

Source of truth: `SPEC.md`, the pinned `spec/openapi.yaml` (BCB API Pix 2.11.0-rc1),
RFC 5280 and the BCB “Manual de Padrões para Iniciação do Pix”.
Every regression was written first, observed failing, then fixed. No existing test
was deleted or skipped; the two assertions that encoded findings 3 and 7 were
corrected with an in-code citation of the reviewer finding.
